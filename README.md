# Undangan Digital

Web undangan pernikahan digital untuk bisnis jasa undangan. Admin (pemilik bisnis) membuat undangan
tiap pasangan lewat formulir; tamu menerima link pribadi berisi nama mereka.

- Stack: Next.js + Supabase + Tailwind CSS, di-deploy ke Vercel.
- Rancangan lengkap: [docs/superpowers/specs/2026-11-10-undangan-digital-design.md](docs/superpowers/specs/2026-11-10-undangan-digital-design.md)
